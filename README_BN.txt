GitHub Pages-এ আপলোড:
1) Repository-তে পুরোনো ফাইল এখনই মুছবেন না; আগে backup/branch রাখুন।
2) এই ZIP Extract করুন।
3) Extract করা index.html এবং assets ফোল্ডার repository-র root-এ আপলোড করুন।
4) assets ফোল্ডারের ভেতরে faruk-logo.jpg থাকতে হবে।
5) Commit changes করে GitHub Pages সাইট রিফ্রেশ করুন।
